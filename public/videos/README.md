# Tutorial preview videos

Drop your **3-second looping MP4 previews** of the finished cake toppers here.

The product cards autoplay these on loop (muted). File names must match the
`video` paths in `src/data/products.js`:

| File                      | Tutorial             |
| ------------------------- | -------------------- |
| `sugar-peony.mp4`         | Sugar Peony Topper   |
| `gold-monogram.mp4`       | Gold Leaf Monogram   |
| `fondant-bunny.mp4`       | Fondant Bunny Figure |
| `ruffle-rose.mp4`         | Ruffle Rose Cascade  |
| `pearl-crown.mp4`         | Pearl & Crown Topper |
| `butterfly-set.mp4`       | Wafer Butterfly Set  |

Tips for the previews:

- Keep them short (~3s) and small (ideally < 2 MB each) so the page stays fast.
- Square (1:1) framing looks best — the card crops to a square.
- Export as `.mp4` (H.264). Until a file exists, the card shows a pretty
  gradient + emoji placeholder automatically, so the site still looks complete.
